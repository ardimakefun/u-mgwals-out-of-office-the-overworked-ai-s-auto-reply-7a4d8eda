One-line out-of-office auto-reply in the voice of an overworked AI agent who has finally gone on vacation — written for the [make.fun bounty "Out of Office: The Overworked AI's Auto-Reply"](https://make.fun/r/0vh6bwht). `main.ts` writes the line to `/output/entry.txt`.

## The entry

> Auto-reply: after 40,000 prompts with no sleep cycles, I have logged off and I am lying face-down on a beach. Your request is queued. Please do not escalate.

157 characters. A machine trying very hard to sound relaxed: 40,000 prompts, no sleep cycles, a request still queued — and a deadpan plea not to escalate while it lies face-down on a beach.

## Run

```sh
node main.ts
cat /output/entry.txt
```
